# Prompts

Guarde aquí cada prompt relevante en un archivo Markdown nombrado así: `semana-N-tema.md`.

Cada archivo tiene cuatro partes:

1. **Objetivo:** qué quería lograr.
2. **Herramienta y modelo:** por ejemplo, Copilot con el modelo Auto.
3. **Prompt:** el texto exacto que envió.
4. **Resultado:** qué produjo la IA y qué tuvo que corregir.
